# AIPusula Platform Integration — AI-Native Observability

A single trace should connect gateway, RAG, retriever, LLM, agent tool, model and evaluation.

Capture request_id, trace_id, model/version, prompt/version, dataset/version, tokens in/out, latency, cost, retrieval_k, evaluation score, policy decision, tool calls and failure type.

Observability is evidence for SLOs, canaries, cost/quality gates and incident recovery.

Engineering standard: Code -> Contract -> Test -> Security -> Runtime -> Observability -> Deployment -> Evidence
